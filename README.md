# AI Local — Material de Estudo do Aluno

Aulas interativas, glossário e diagramas do curso de IA Local da **AILOCAL**: dos fundamentos de rodar modelos na sua máquina até montar um fluxo de agente com skills, MCP e guardrails.

## Como usar

Não precisa instalar nada. Tudo funciona offline, direto no navegador.

1. Baixe o material:
   - **Sem Git:** clique em **Code → Download ZIP** aqui no GitHub e extraia a pasta no seu computador.
   - **Com Git:** `git clone` deste repositório.
2. Abra o arquivo `index.html` no seu navegador (dois cliques já resolvem).
3. Siga as aulas pela página inicial. Seu progresso e os quizzes ficam salvos no próprio navegador.

Para manter o material atualizado, baixe o ZIP de novo ou rode `git pull` na pasta clonada.

## O que tem aqui

| Pasta | Conteúdo |
|-------|----------|
| `index.html` | Página inicial com a trilha completa |
| `lessons/` | Aulas interativas com simuladores e quizzes |
| `reference/` | Glossário, diagramas e índice de quizzes |
| `assets/` | Estilos e scripts usados pelas aulas |
